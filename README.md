# 🛡️ CyberLearn

**CyberLearn** is an interactive learning platform designed to help beginners and aspiring cybersecurity professionals develop practical skills in **programming, ethical hacking, penetration testing, and cybersecurity**.

The platform combines structured learning materials with hands-on challenges, coding exercises, and interactive environments to make cybersecurity education more practical and engaging.

---

## 🚀 Features

### 📚 Coding Academy

Learn programming through structured courses and practical exercises.

* Python
* JavaScript
* Bash
* Programming fundamentals
* Coding challenges

### 🛡️ Hacking Lab

Practice cybersecurity concepts through controlled and educational challenges.

* Beginner challenges
* Intermediate challenges
* Advanced challenges
* Capture The Flag (CTF) exercises
* Security concepts

### 💻 Interactive Sandbox

Experiment with code and commands in an interactive learning environment.

* Code editor
* Output preview
* Terminal-style interface
* Practice environment

### 📊 Learning Dashboard

Track your learning progress and achievements.

* Course progress
* Completed challenges
* Learning statistics
* Achievements
* Quick resume

### 🎮 Gamified Learning

Make learning more engaging with:

* XP points
* Levels
* Challenges
* Achievements
* Progress tracking

---

## 🎯 Learning Paths

CyberLearn is designed around several learning paths:

### 1. Programming Fundamentals

Learn the basics of programming and problem solving.

### 2. Web Development

Build an understanding of modern web technologies.

### 3. Cybersecurity Fundamentals

Learn the foundations of cybersecurity and information security.

### 4. Ethical Hacking

Understand ethical hacking methodologies and security testing.

### 5. Penetration Testing

Learn how authorized security assessments are performed.

### 6. Capture The Flag

Apply your knowledge through controlled security challenges.

## 🔐 Educational Purpose

CyberLearn is intended for **education and authorized security testing**.

All cybersecurity exercises should be performed only on systems, applications, networks, and environments where you have explicit permission to test.

The project does not encourage unauthorized access, disruption, or illegal activity.

## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/CyberLearn.git
```

Move into the project directory:

```bash
cd CyberLearn
```

Open `index.html` in your browser.

For development, you can also use a local development server such as the Live Server extension in VS Code.
